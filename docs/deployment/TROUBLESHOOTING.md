# 常见问题排查 TROUBLESHOOTING

> 日期：2026-07-08（更新）
> 面向：iWorkHelper 使用者与维护者。错误提示均为中文、含建议操作；日志位置见文末。

## 0. Outlook 启动相关问题（优先级最高）

| 现象 | 原因 | 处理 |
|------|------|------|
| 启动 Outlook 时提示"加载项导致启动缓慢，已被禁用" | Outlook Resiliency 检测到启动时间超过阈值（通常 > 1000ms） | 详见 `docs/deployment/OUTLOOK_ADDIN_RESILIENCY_GUIDE.md` 第 2-5 章 |
| 在禁用列表中选择"启用"后，下次启动仍被禁用 | 代码中某些操作仍然耗时 | 查看启动诊断日志 `{归档目录}\logs\yyyy-MM-dd.log` 中的 `Startup 总耗时`，反馈给开发团队 |
| 提示关闭也缓慢 | Shutdown 中可能有耗时操作 | 查看日志中的 `Shutdown 总耗时` 值 |

## 1. 配置类

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示“尚未配置归档目录” | 未设置归档目录 | 打开【设置】选择归档文件夹 |
| 提示“归档目录不存在” | 目录被删除/路径变化 | 在设置中重选目录，或保存时同意自动创建 |
| 提示“归档目录无写入权限” | 目录只读/受保护 | 更换目录或检查该目录写入权限 |
| 提示“归档目录路径格式非法” | 路径含非法字符 | 重选一个有效本地目录 |
| 保存时提示“配置不完整” | 启用 OCR 但缺 AK/SK | 填写 API Key 和 Secret Key |
| 提示“接口/Token 地址无效” | 非 http(s) 地址 | 填写正确的 http(s) 地址 |
| 提示“超时时间需在 3000–120000” | 超时值不合理 | 设为 3000–120000 毫秒 |
| 点“测试 OCR 配置”提示密钥无效 | AK/SK 错误或已重置 | 核对/更新 API Key、Secret Key |
| 点“测试 OCR 配置”提示网络异常 | 无网络/代理 | 检查网络或代理 |
| 换机器/换用户后 OCR 失效 | DPAPI 仅当前用户可解密 | 在设置中重新输入 Secret Key 并保存 |

## 2. 运行类（归档）

| 现象 | 原因 | 处理 |
|------|------|------|
| 提示“未选择邮件” | 未在 Outlook 选中邮件 | 先选中要归档的邮件 |
| 某邮件“已跳过（无 PDF 附件）” | 该邮件无 PDF | 正常，确认邮件含 PDF |
| 某邮件“PDF 合并失败，已跳过” | PDF 加密/损坏 | 单独检查该邮件附件；其他邮件不受影响 |
| 某邮件“需要配置 OCR” | 本地字段不足且 OCR 未启用/未配置 | 在设置启用并配置在线 OCR |
| 归档文件名含很多下划线 | 地址中 `\|` 等非法字符被清理为 `_` | 正常，Windows 文件名限制 |
| 同名文件未被覆盖 | 自动追加 (1)(2) 序号 | 正常，保护已有文件 |
| 提示“已有归档任务正在运行” | 确有另一归档任务未结束（真正并发/快速连点） | 等待当前任务完成后再试 |
| 点归档**立即**提示“已有归档任务正在运行”（每次必现） | **已修复（2026-07-10）**：旧版预检查前先置运行标志、预检查又检查该标志导致自我阻断 | 更新到修复版即可；根因与验证见 `docs/development/ARCHIVE_RUNNING_STATE_BUG_REPORT.md`。该问题清缓存/正式部署/换调试方式都无法解决，因为是源码逻辑顺序错误 |

## 2.1 分流处理相关

| 现象 | 说明 |
|------|------|
| 滴滴邮件的发票+行程单合并为一个文件 | 正常，滴滴邮件按合并归档 |
| 普通发票每张单独归档 | 正常，常规发票按 PDF 单独归档（命名用常规发票模板） |
| 某个 PDF 命名为 `未识别_原名.pdf` | 该 PDF 未能识别为滴滴/常规发票，按未识别归档（不丢文件） |
| 一封邮件产出多个归档文件 | 正常（常规发票多张 / 含未识别 PDF） |
| 无 PDF 附件的邮件未处理 | 正常，直接跳过并计入“跳过” |
| 普通发票被误当未识别 | 该 PDF 缺发票特征关键词；可用 `OfflineTester --classify` 复核，必要时反馈样例校准 |

## 3. 识别相关

- **本地识别不稳定/取不到起点终点**：多为图片型 PDF 或异版式。启用在线 OCR 兜底；本地已用坐标行重建，对同版式滴滴行程单稳定（见 LOCAL_TEXT_RECOGNITION_DIAGNOSTIC_REPORT）。
- **在线 OCR 识别成功但字段为空**：票据版式可能不受支持；文件仍会归档，可人工核对。

## 4. 日志与报告位置

- 日志：`{归档目录}\logs\yyyy-MM-dd.log`，或 `%AppData%\iWorkHelper\logs\yyyy-MM-dd.log`。
- 归档报告：同目录 `archive-report-yyyyMMdd-HHmmss.txt`（每次归档一份，含每封邮件明细）。
- 汇总弹窗会显示本次报告路径与日志路径。
- **日志/报告不含 AK/SK/token**；请勿把 `user.config`、日志、报告、样例 PDF 提交到仓库。

## 5. 维护者：离线复现

```
:: 预检查/配置校验
OfflineTester.exe --preflight <归档目录>
:: 查看某错误码文案

OfflineTester.exe --simulate-error list
:: 本地识别诊断
OfflineTester.exe sample --local-only --dump-local-debug
:: 自测（含容错）
OfflineTester.exe --selftest
```
