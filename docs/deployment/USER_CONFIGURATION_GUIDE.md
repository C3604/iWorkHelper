# 用户配置指南 USER_CONFIGURATION_GUIDE

> 日期：2026-07-07
> 面向：iWorkHelper 使用者（在 Outlook 中配置与使用）。

## 1. 打开设置

Outlook 功能区 → “工作助手” → “设置”。

## 2. 归档目录

- 点“选择文件夹”选择归档根目录 → 保存。
- 归档后的合并 PDF 会存放到该目录。

## 3. 命名规则（滴滴发票 / 常规发票）

设置页有两个命名规则输入框：
- **滴滴发票**（默认 `{乘车日期}_{金额}_{出发地点}_{到达地点}`）——滴滴邮件合并 PDF 用。例 `20260518_138.46_上海虹桥站_上海市徐汇区.pdf`。
- **常规发票**（默认 `{开票日期}_{金额}_{销售方名称}`）——普通发票 PDF 单独归档用。例 `20260526_138.46_某某科技有限公司.pdf`。
- 无法识别的其它 PDF：固定按 `未识别_{原始文件名}.pdf` 归档（无需配置）。
- 归档按邮件/PDF 类型自动分流，详见 TROUBLESHOOTING 与规范文档。
- 点“变量说明”查看全部可用变量；点“预览”查看示例文件名。
- 取值优先级：`{乘车日期}`=行程出发日期>开票日期；`{金额}`=行程金额>价税合计>金额；`{出发地点}`=行程起点；`{到达地点}`=行程终点。
- 留空则用默认模板；字段严重不足时自动用“未识别票据_邮件主题_时间戳”。
- 空字段自动跳过、非法字符自动清理、同名自动加序号、不覆盖。

## 4. 在线 OCR（百度智能财务票据识别）

- 勾选“启用在线 OCR”，填写 API Key / Secret Key（Secret Key 输入框为密码遮罩，保存后 **DPAPI 加密**存储）。
- 接口地址默认 `multiple_invoice`；超时、返回置信度/位置/验真、最大页数、优先本地解析、自动回退在线 OCR 均可配置。
- 策略：**优先本地文本解析**；文本型 PDF 走本地；无文本层/字段不足时回退在线 OCR。
- 安全：AK/SK/token 不写入日志；Secret Key 以 `DPAPI:` 前缀加密保存在 `user.config`。

### 测试 OCR 配置
填好 AK/SK 后可点“测试 OCR 配置”按钮：仅测试连通性（获取 Token，不上传 PDF、不显示 token）。成功提示“配置可用”；失败给出具体原因（密钥错误/网络异常/未授权）。

### 开发期批量落地（可选）
可用离线工具把配置安全写入本机（Secret Key DPAPI 加密）：
```
set BAIDU_OCR_AK=你的APIKey
set BAIDU_OCR_SK=你的SecretKey
OfflineTester.exe --save-baidu-config
```
配置文件 `%AppData%\iWorkHelper\baidu-ocr.config.xml`（已 `.gitignore` 忽略，勿提交）。

## 5. 归档流程（以“邮件”为单位）

- 选中一封或多封邮件 → 点“归档”。
- **每封邮件**内的发票 PDF 与行程单 PDF 会**合并为一个 PDF**再识别/命名/归档。
- 处理过程显示**进度窗口**（总邮件数、已处理数、当前邮件、当前阶段、百分比）。
- 点“归档”后先做**预检查**（选中邮件/归档目录/临时目录等），有问题会一次性列出并阻止进入，不会中途才失败。
- 处理过程显示进度窗口；某封失败会提示“已继续下一封”。
- 结束后弹出一次汇总（成功/部分/需 OCR/跳过/失败/合并数），并显示**结果报告路径**与日志路径。
- 单封邮件失败不影响其它邮件；详细过程写入日志与报告 `archive-report-*.txt`。
- 常见问题排查见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 6. 日志位置

`{归档目录}\logs\yyyy-MM-dd.log`（或 `%AppData%\iWorkHelper\logs\`）。日志不含 AK/SK/token 明文。

## 7. 安全提醒

- 请勿把 `user.config`、`baidu-ocr.config.xml`、样例 PDF、日志提交到代码仓库（`.gitignore` 已覆盖）。
- 开发/调试完成后建议在百度智能云控制台**重置 Secret Key**。
