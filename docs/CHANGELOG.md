## v1.2.260713.1（2026-07-13）

首个正式发布版本。

### 核心功能

- **Outlook VSTO 加载项**：在 Outlook 功能区提供"归档"和"设置"入口。
- **批量邮件处理**：选中多封邮件，一键批量识别、合并、命名和归档 PDF 附件。
- **邮件分流**：自动识别滴滴发票邮件、常规发票邮件、未识别 PDF 和无 PDF 邮件，分别处理。
- **滴滴发票合并归档**：同一封邮件的发票和行程单 PDF 合并为一个文件后识别、命名、归档。
- **常规发票单独归档**：每张常规增值税发票 PDF 单独识别、命名、归档。
- **未识别 PDF 保留**：无法识别的 PDF 按 `未识别_{原始文件名}` 归档，不丢弃文件。
- **本地文本识别**：基于 PdfPig 文本抽取与规则识别，支持坐标行重建。
- **常规发票专用识别器**：候选评分、分区解析、商品明细提取。
- **百度 OCR 在线解析**（仅外网版）：本地字段不足时自动回退百度智能财务票据识别 API。
- **自定义命名模板**：支持滴滴发票、常规发票、未识别 PDF 三类模板，变量说明与预览。
- **归档预检查**：归档前检查配置、目录、权限等，有问题一次性列出。
- **归档运行锁**：防止重复点击和并发归档。
- **进度展示**：进度窗口显示总邮件数、已处理数、当前阶段和百分比。
- **结果汇总与报告**：归档完成后弹出汇总，详细结果写入归档报告文件。
- **Secret Key DPAPI 加密**：百度 OCR Secret Key 使用 Windows DPAPI 保护，不明文存储。
- **OfflineTester 离线测试工具**：不依赖 Outlook，支持自测、本地识别、OCR 联调和回归对比。

### 内网版与外网版

- **Release-Intranet**（内网版）：禁用在线解析，隐藏 OCR 相关 UI，不产生外网请求。
- **Release-Internet**（外网版）：允许配置百度 OCR 在线解析，本地不足时自动回退。
- 默认安全策略：未定义 `INTERNET_BUILD` 即禁用在线解析。

### 已知限制

- 仅支持 Windows + Outlook 桌面版。
- 依赖 VSTO Runtime、Office 运行时和 .NET Framework 4.8。
- 本地识别依赖 PDF 文本层质量，扫描件/图片型 PDF 需要 OCR。
- Outlook 可能因启动性能、签名或信任策略禁用加载项。
- 签名使用临时证书，正式部署需替换为正式代码签名证书。
- VSTO 部署通常通过 ClickOnce 或手动配置注册表，本仓库未包含安装包。
