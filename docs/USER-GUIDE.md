# 使用指南

## 1. 简介

iWorkHelper 是 Outlook 加载项，用于批量处理邮件中的 PDF 附件（发票、行程单），完成识别、合并、命名和归档。

## 2. 适用场景

- 批量处理滴滴出行发票（发票+行程单合并为一个PDF归档）
- 批量处理常规增值税发票（每张单独归档）
- 处理未识别PDF（保留原始文件名归档）
- 内网环境（仅本地解析）或外网环境（可选百度OCR在线解析）

## 3. 安装要求

- Windows + Outlook 桌面版
- .NET Framework 4.8
- VSTO Runtime 4.0

## 4. 首次配置

1. Outlook 功能区 → 工作助手 → 设置
2. 设置归档目录（PDF归档后存放位置）
3. (可选) 自定义命名模板
4. (外网版) 配置百度OCR API Key / Secret Key
5. 保存（直接关闭窗口，无多余弹窗）

## 5. 归档操作

1. 在 Outlook 中选中一封或多封邮件
2. 点击功能区"工作助手 → 发票归档 → 归档"
3. 系统先执行预检查（归档目录、邮件选择等）
4. 预检查通过后显示进度窗口
5. 处理完成后显示汇总（成功/部分成功/需OCR/跳过/失败数量）
6. 查看归档目录中的文件和报告

## 6. 处理规则

### 邮件分类

- 滴滴发票邮件：发票+行程单PDF合并为一个文件后归档
- 常规发票邮件：每张发票PDF单独归档
- 未识别PDF：按"未识别_{原始文件名}.pdf"归档（不丢文件）
- 无PDF附件邮件：自动跳过

### 识别策略

- 本地优先：使用PdfPig提取PDF文本层，通过规则识别
- 在线兜底（仅外网版）：本地字段不足时自动回退百度OCR
- 内网版：只使用本地解析，不产生任何外网请求

### 默认命名规则

- 滴滴发票：{乘车日期}_{金额}_{出发地点}_{到达地点}.pdf
  例: 20260518_138.46_上海虹桥站_上海市徐汇区.pdf
- 常规发票：{开票日期}_{金额}_{销售方名称}.pdf
  例: 20260526_138.46_某某科技有限公司.pdf
- 未识别PDF：未识别_{原始文件名}.pdf
- 字段不足时：未识别票据_{邮件主题}_{时间戳}.pdf

### 文件名处理

- 空字段自动跳过（不产生多余下划线）
- 非法字符自动清理
- 同名文件自动追加序号(1)(2)...不覆盖

## 7. 进度与结果

- 进度窗口显示：总邮件数、已处理数、当前邮件、当前阶段、百分比
- 结束后一次性汇总弹窗
- 详细结果在归档报告（archive-report-*.txt）和日志中

## 8. 日志与报告

- 日志：{归档目录}\logs\yyyy-MM-dd.log
- 报告：{归档目录}\logs\archive-report-yyyyMMdd-HHmmss.txt
- 日志和报告不含敏感信息（API密钥、token等）

## 9. 安全说明

- Secret Key 使用 Windows DPAPI 加密存储
- 更换机器或Windows用户后需重新输入Secret Key
- 内网版禁止在线解析，即使配置文件残留在线参数也不调用
