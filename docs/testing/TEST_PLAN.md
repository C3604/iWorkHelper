## 2. 验证要点与检查位置

- **命名规则**：核对文件名格式与非法字符清理（`ArchiveNamingRule` / `FileNameSanitizer`）。
- **不覆盖**：确认 T11 生成 `xxx(1).pdf`，原文件不变（`ArchiveExecutor` 二次防御 + `PathHelper.GetNonConflictingPath`）。
- **日志**：检查 `{归档目录}\logs\yyyy-MM-dd.log` 或 `%AppData%\iWorkHelper\logs\`，应含每步 INFO 与异常 ERROR。
- **临时文件**：归档成功后 `%AppData%\iWorkHelper\temp` 中对应临时文件应被清理；失败时保留。
- **汇总口径**：成功 + 部分成功 + 需要 OCR + 跳过 + 失败 = 附件总数。

## 3. 人工验证步骤（推荐顺序）

1. 在装有 Outlook（Office 365）的机器上，用 VS2022 打开 `iWorkhelper.sln`，F5 启动（自动挂载插件到 Outlook）。
2. 在“工作助手”功能区点“设置”，选择一个归档目录，保存。
3. 依次执行 T1→T2→T3→T4→T6→T11→T13，核对提示与归档目录、日志。
4. 若有真实滴滴样例：执行 T6/T7，核对字段与命名，据此校准 `LocalTextInvoiceRecognizer` 正则（见 FIELD_EXTRACTION_SPEC）。
