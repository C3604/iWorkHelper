## 0. 前置

- Windows + Outlook（桌面版，Office 365 / 2016+），已装 VSTO 4.0 运行时。
- VS2022 打开 `iWorkhelper.sln`，F5 启动（自动挂载插件到 Outlook 调试实例）。
- 准备：含 PDF 附件的邮件（文本型滴滴发票+行程单、常规发票、如有图片型 PDF）、无附件邮件、非 PDF 附件邮件、非邮件项（日历/任务）。
- 外网版才有 OCR 配置项（内网版隐藏，见 [../architecture/BUILD_VARIANTS.md](../architecture/BUILD_VARIANTS.md)）。

## 2. DPAPI 专项（外网版）

- 首次用旧版本（明文 SK）升级后打开设置/归档，确认 user.config 中 SK 自动变为 `DPAPI:` 密文（迁移生效）。
- 把 user.config 拷到另一 Windows 用户/机器打开设置，确认提示"无法解密，请重新输入"，且插件仍正常加载。

## 3. 启动性能专项

连续启动 Outlook 5 次，观察是否出现"启动缓慢"提示；查看日志 `Startup 总耗时`（健康 < 500ms）与 Event ID 45 的 `TimeTaken`。诊断方法见 [../deployment/STARTUP_PERFORMANCE.md](../deployment/STARTUP_PERFORMANCE.md)。
